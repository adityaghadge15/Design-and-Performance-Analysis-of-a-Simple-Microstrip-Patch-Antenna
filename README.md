# Design and Performance Analysis of a Simple Microstrip Patch Antenna

## Overview
This repository contains the CST Studio Suite simulation model for a Microstrip Patch Antenna.

## Project Specifications
- **Operating Frequency:** 2.4 GHz (or your frequency)
- **Substrate Material:** FR-4 (Relative Permittivity epsilon_r = 4.4)
- **Substrate Height:** 1.6 mm
- **Feed Type:** Inset Feed / Microstrip Line Feed

## File Structure
- `Patch Antenna.cst`: Main CST Studio Suite project file.
- `Model/3D/`: Core 3D CAD parameters and geometry specs.

## How to Run
1. Download or clone this repository.
2. Open `Patch Antenna.cst` using CST Studio Suite (Version 2020 or newer).
3. Run the Transient / Frequency Domain Solver to view S-parameters (S_{11}) and 3D Radiation Patterns.
